## Regenerating the generated files

```
python demo/tools/make_inspection_reports.py
python demo/tools/make_pid.py
```

Both scripts are deterministic (fixed seeds, no clock), so they produce byte-identical files.
They use only Pillow, PyMuPDF and the Windows Arial fonts (`%WINDIR%\Fonts`).
